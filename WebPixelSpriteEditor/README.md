# PixelSpriteEditor（Web版）

90年代の対戦格闘ゲーム（ストリートファイターII風）のキャラクタースプライトを
描くためのドット絵エディタです。[`PixelSpriteEditor/`](../PixelSpriteEditor/)
（Java/Swing版）と機能面ではほぼ同じものを、**HTML + CSS + 素のJavaScript
だけ**（外部ライブラリ・ビルドツール一切不要）で作り直し、**iPhoneなど
スマートフォンのブラウザでも動く**ようにしたものです。

Java/Swing版はデスクトップ専用（Windows/Linux/macOS）で、スマートフォンの
OS上ではそのまま動作できません。このWeb版はその制約を解消するために、
Java版と**並行して**追加された実装です。どちらも今後メンテナンス対象です。

## 使い方（とにかく開くだけ）

`index.html` をブラウザで開くだけで動きます。ビルドも `npm install` も
不要です。

- **PC**: `index.html` をダブルクリックする、またはブラウザにドラッグ＆
  ドロップする
- **iPhone**: このフォルダをどこかでホスティングして（後述）Safariで開く。
  共有メニューの「ホーム画面に追加」をすると、アイコンタップで直接起動でき
  ます（フルスクリーンではなく通常のSafariタブとして開きます）

> なぜ `file://` で直接開けるのか：スクリプトはすべて `type="module"` では
> なく通常の `<script src="...">` として読み込んでいます。ES Modules は
> `file://` から他のファイルを読み込む際にブラウザのCORS制限に引っかかる
> ことがありますが、通常のスクリプトタグにはその制限がないため、ローカル
> ファイルをダブルクリックするだけで動作します。

### iPhoneで試す場合（ホスティングの一例）

iPhone本体からは `file://` で直接このフォルダを開けないため、何らかの形で
HTTP(S)経由にする必要があります。例えば:

- このリポジトリをGitHub Pages等で公開し、そのURLをiPhoneのSafariで開く
- 同じWi-Fiにいる PC 上で `npx http-server WebPixelSpriteEditor` のような
  簡易サーバーを立て、PCのローカルIPアドレス経由でiPhoneから開く

## 対応環境

- PC: 最近のChrome / Safari / Firefox / Edge（Canvas 2D, Pointer Events,
  ResizeObserver が使えるブラウザ）
- スマートフォン: iOS Safari 15以降 / Android Chrome 相当

## 操作方法

### マウス / トラックパッド

| 操作 | 内容 |
|---|---|
| 左クリック（鉛筆/消しゴム） | ドラッグで連続描画（間の座標も自動補間） |
| 左クリック（塗りつぶし） | クリックした位置と同じ色の4方向連結領域を塗る |
| 左クリック（スポイト） | クリックした位置の色を現在色にする |
| 左クリック（直線） | 押した位置から離した位置まで直線を描画 |
| 左クリック（選択） | ドラッグで矩形選択 |
| 右クリック | コンテキストメニュー（コピー/切り取り/貼り付け/削除/塗りつぶし/反転/全選択/選択解除） |
| Ctrl+ホイール | ズームイン・アウト（カーソル位置が中心。ホイール単体では反応しません） |
| 中ボタンドラッグ / Space+ドラッグ | キャンバスをパン |

### タッチ（iPhone / Android）

| 操作 | 内容 |
|---|---|
| 1本指ドラッグ | 選択中のツールで描画（鉛筆/消しゴム/塗りつぶし/スポイト/直線/選択、いずれもマウスと同じ） |
| 2本指ピンチ | ズームイン・アウト（2本指の中間点が中心） |
| 2本指ドラッグ | キャンバスをパン |
| パレット/最近使った色を長押し | その色を削除（右クリックの代わり） |

右クリックに相当する操作がないため、コピー/切り取り/貼り付け/反転などは
画面上部の「Edit」メニューから行います。狭い画面では色/レイヤー/フレームの
各パネルは画面下から出てくるシート（下部の「色」「レイヤー」「フレーム」
タブをタップで開閉）になります。

## 機能一覧（Java版との対応）

- ツール: 鉛筆・消しゴム・塗りつぶし（4方向）・スポイト・直線・矩形選択
- レイヤー: 表示/非表示切替、追加・複製・削除・並べ替え
- アニメーションフレーム: 追加・複製・削除・並べ替え、8fpsでの再生プレビュー、
  オニオンスキン（ひとつ前のフレームのみ半透明表示）
- 選択範囲: コピー/切り取り/削除/塗りつぶし/左右反転/上下反転/全て選択/選択解除、
  貼り付けはカーソル追従のプレビュー→クリックで確定
- 色: RGBAスライダー+数値入力、デフォルトパレット（15色+透明・編集不可）＋
  自分で作成できるパレット、最近使った色
- キャンバス: ニアレストネイバー拡大、グリッド線、16x16ガイド、ホバー
  ハイライト、ズーム/パン
- ファイル: 新規キャンバス、PNGとして開く/保存、プロジェクトとして保存/
  読み込み、キャンバスのリサイズ（3x3基準位置）、スプライトシートとして
  書き出し（列数指定）
- Undo/Redo: レイヤーごとに独立（ストローク単位。レイヤー/フレームの
  追加・削除自体はJava版と同様に対象外）

## プロジェクトファイルについて（Java版との違い）

Java版の `.pxproj` は `java.util.zip` で書いた実際のZIPファイル（レイヤー
ごとのPNG + `manifest.properties`）ですが、Web版では**同じ発想を素の
ブラウザAPIだけで実現するため、JSON形式**（`*.pxproj.json`）を使っています。
自前でZIP書き込み（圧縮・CRC32計算）を実装する代わりに、`canvas.toDataURL()`
で得たPNGデータURLをレイヤーごとにJSONへ埋め込んでいます。中身はテキスト
エディタで開いてそのまま確認できます。

この形式はJava版の `.pxproj`（ZIP）とは**互換性がありません**。両者の間で
プロジェクトファイルを直接読み込むことはできず、それぞれの版で保存した
ファイルはそれぞれの版で開いてください。PNG書き出し（1枚絵）はどちらの版
でも同じ標準PNGなので、そちらは相互に問題なく使えます。

## ファイル構成

```
WebPixelSpriteEditor/
├─ index.html              ページ本体。パネル/ツールバーのDOM構造と、
│                           全スクリプトの読み込み（依存順）
└─ src/
   ├─ style.css             固定ダークテーマ、レスポンシブレイアウト
   │                         （860px以下でパネルがボトムシート化）
   ├─ lineUtil.js            ブレゼンハムの線分補間（Pencil/Eraser/Line共用）
   ├─ history.js             レイヤーごとのUndo/Redo（ストローク単位の
   │                         全面ImageDataスナップショット方式）
   ├─ project.js             Layer/Frame/Project/ColorPalette のデータモデル
   ├─ state.js               EditorState（現在のツール・カメラ・色・選択範囲・
   │                         クリップボード等）とpub-subイベント
   ├─ tools.js               鉛筆/消しゴム/塗りつぶし/スポイト/直線/選択の
   │                         各ツールと、選択範囲操作（コピー等）
   ├─ canvasPanel.js         キャンバス描画（ズーム/グリッド/ガイド/
   │                         オニオンスキン/各種プレビュー）と、Pointer
   │                         Eventsによるマウス・タッチ入力（ピンチズーム/
   │                         2本指パンを含む）
   ├─ colorPanel.js          RGBAスライダー・パレット・最近使った色のUI
   ├─ layersPanel.js         レイヤー一覧UI
   ├─ framesPanel.js         フレーム一覧・再生プレビューUI
   ├─ dialogs.js             新規/リサイズ/スプライトシート書き出しの
   │                         モーダルダイアログと右クリックメニュー
   ├─ fileio.js              PNG/プロジェクトの開く・保存、スプライトシート
   │                         書き出し
   └─ main.js                起動処理。全パネルの初期化、File/Editメニュー、
                             キーボードショートカット、モバイル用パネル
                             タブの配線
```

すべて`<script>`タグの読み込み順に依存が解決される素朴な構成です（モジュール
バンドラ不使用）。新しいツールを追加する場合は `PSE.Tools` に
`onDown`/`onMove`/`onUp`/`onCancel` を持つオブジェクトを追加し、ツール
バーのボタンに `data-tool` 属性を振るだけで済むようにしています。

### 現時点の制限事項

- Java版の `.pxproj`（ZIP）とは互換性がありません（上記参照）
- レイヤー/フレームの追加・削除自体はUndo対象外（Java版と同じ仕様）
- 選択範囲は矩形のみ
- コピー＆ペーストはアプリ内のみで完結し、OSのクリップボードとは連携しません
- ネイティブアプリではないため、ホーム画面への追加はSafariのブックマーク的な
  起動（フルスクリーンPWA化やオフライン動作)までは行っていません
